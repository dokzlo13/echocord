# EC-002 Prove complete Windows dependency build from WSL

Depends on EC-001. Owner unassigned. Scope: a bounded probe plus reproducible build scripts; coordinator owns manifests and lockfiles. Keep code and build caches in WSL.

Acceptance: compile/link chosen capture, Songbird/DAVE/Opus, and Tauri dependencies for Windows MSVC; run the binary on Windows; enumerate actual recording devices; open and close a minimal WebView shell. Record exact versions/features and native build fixes. No live Discord token is required for dependency linkage or enumeration.

Check cargo-xwin, LLVM/clang-cl, CMake/Ninja, SDK/CRT caching, runtime DLL requirements, and artifact launch paths. Verify whether the Tauri shell can be built with frontend assets produced in WSL. Prefer an unpackaged executable initially; defer installer/signing.

If cross-compilation fails, isolate the offending dependency and attempt a documented targeted fix. A native or remote Windows builder would change the WSL build constraint and needs an explicit project decision; do not silently introduce one.

Deliver commands and actual outcomes, commit lockfiles and validated tool pins, document remaining runtime tests. Next action: claim after EC-001 and review TECHNOLOGY/DEVELOPMENT.
