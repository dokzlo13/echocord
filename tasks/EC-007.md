# EC-007 Select vetted upstream skills and documentation

Depends on EC-002. Active research attempt a1, coordinated in main with separate read-only skill-provenance and desktop-UX reviewers. Scope: research existing skills for the validated Rust/Tauri/React/TypeScript/Mantine stack and visual verification workflow. Do not create synthetic skills or placeholders.

Acceptance: inspect real candidates' source, license, pinned revision, recent maintenance, meaningful adoption/review evidence, required tools, and actual applicability. Prefer a small set. Evaluate selected skills on a representative UI task before relying on them. If no suitable candidate exists, state that outcome and use official documentation without inventing a skill.

Keep installed resources in a shared repository skill folder only when license-compatible and generic. Avoid copying entire external documentation sites. Record official documentation links and version-specific integration notes; vendor only material that materially supports the workflow and permits redistribution. Keep account configuration out of Git.
