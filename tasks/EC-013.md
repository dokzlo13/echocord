## Visualization design constraints

Explore restrained queue/buffer diagnostics and dynamic metering as part of the audio-tool identity. Keep details contextual if they overload the primary route controls. Existing scalar telemetry can establish input level and queue occupancy; it cannot establish end-to-end delay or listener delivery. An actual post-gain meter would need native telemetry at the reader boundary. See QUALITY.md for the isolated rendering, visibility and bounded update requirements. The current alpha still delivers whole snapshots to its top-level React subscriber; the redesign must remove this coupling before claiming metering performance acceptance.
