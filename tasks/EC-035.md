# EC-035 Discord room source proof and lifecycle design

Queued as the next owner priority; blocked until EC-033 is delivered. EC-034 completed read-only feasibility research. No implementation worker, branch or worktree is assigned yet. This record is a proposal to review, not a shipped capability or a replacement for the active destination epoch.

Prove one ordinary Discord voice-room source, combining participants into one native source stream, with local playback or different-server destinations. Propose explicit Capture to join, Stop to release, source gain/mix mute, idle restore and no audio-file persistence. Keep participant mute and Stage channels for later. Prevent source/output coexistence in the same server in this first slice; broader duplex requires reviewed mix-minus before the shared clamp.

First establish receive-feature Windows build viability and a tokenless synthetic receive adapter experiment for variable packet sizes, concurrent speakers, carry buffers, loss/concealment, SSRC reuse, silence/resume, stale generations and bounded overload. Review library decoder/event-queue resource limits rather than relying only on the downstream ring. Then freeze the room-role/permission, server reservation, disposable receive worker, native input mapping and persistent audio-worker lifetime contract for independent review before production UI/core integration. Parent and frontend must remain sample-free and secrets must remain private.

An explicitly coordinated live proof must include existing/new/leaving participants and encryption transitions, permission/deafen changes, stop/mute/gain, independent output/source survival, playback and cross-server relay. Measure decoded PCM, output submission, listener receipt, latency and sustained resource/drift behavior separately. No automatic room joining, participant capture, messages or output audio is authorized merely by this queued task; use the existing coordinated-test workflow. The final production acceptance plan must name unmeasured behavior and distinguish upstream reports from reproduced failures.
