On removal, surviving ordinals compact to list order; a return to one hides both marker and jump navigation. Stable native IDs, React keys, colour slots and telemetry keys never derive from the ordinal. No reorder control is introduced.

Keep source markers in their current position before the identity; add the same small neutral marker before destination identity without replacing server/device imagery. The single-source header retains On/Muted/Off state without the redundant count; multiple-source summaries retain counts. The single-destination header retains its existing absence of a summary because its card already names state.
