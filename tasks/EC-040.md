## Design checkpoint proposal

Preserve the On Air palette, typography, source colour identity, imagery and card geometry. This is a scoped identification correction. Each section independently shows numbers only when it has at least two cards: the card marker and jump button use the same one-based display ordinal. On removal, surviving ordinals compact to list order; a return to one hides both marker and jump navigation. Stable native IDs, React keys, colour slots and telemetry keys never derive from the ordinal. No reorder control is introduced.

Keep source markers in their current position before the identity; add the same small neutral marker before destination identity without replacing server/device imagery. The single-source header retains On/Muted/Off state without the redundant count; multiple-source summaries retain counts. The single-destination header retains its existing absence of a summary because its card already names state. Article and jump accessible names identify their section, ordinal when shown, and actual identity. All control actions and focus/scroll targets remain keyed to native identity.
